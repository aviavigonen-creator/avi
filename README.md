# מנות של פורים — אתר החנות ופאנל הניהול

אתר מכירה למארזי משלוח מנות בכשרות בד"ץ מהדרין. מתארח ב-GitHub Pages, עם מסד נתונים ב-Supabase.

| קובץ | תפקיד |
|---|---|
| `index.html` + `app.js` | אתר החנות (קטלוג, עגלה, הזמנה, תשלום, נגישות) |
| `admin.html` | פאנל ניהול: לוח בקרה, הזמנות, מוצרים, הגדרות |
| `config.js` | **הקובץ היחיד לעריכה ידנית**: כתובת ומפתח Supabase |
| `images.js` | תמונות המוצרים הראשוניים (עד שמעלים תמונות דרך הפאנל) |
| `supabase/schema.sql` | סכמת מסד הנתונים, הרשאות וסטטיסטיקות |
| `supabase/functions/order-email/` | אוטומציית מיילים (אישור הזמנה + התראה לבעל העסק) |

האתר עובד גם **בלי** מסד נתונים: המוצרים מוטבעים וההזמנות נשלחות בוואטסאפ. עם מסד נתונים נפתחים: שמירת הזמנות, פאנל ניהול, סטטיסטיקות, תשלום ומיילים.

---

## שלב 1: מסד נתונים (10 דקות, פעם אחת)

1. היכנסו ל-[supabase.com](https://supabase.com), פתחו חשבון (אפשר עם GitHub) ולחצו **New project**. שם: `manot`, סיסמה חזקה (שמרו אותה), אזור: **Europe (Frankfurt)**.
2. בתפריט הצד **SQL Editor → New query**. הדביקו את כל תוכן `supabase/schema.sql` ולחצו **Run**. אמור להופיע "Success".
3. **Authentication → Users → Add user → Create new user**: המייל והסיסמה שלכם לפאנל הניהול. סמנו **Auto Confirm User**.
4. **Project Settings → API**: העתיקו את **Project URL** ואת המפתח **anon public**.
5. פתחו את `config.js` במאגר (GitHub → לחיצה על הקובץ → עיפרון), הדביקו את שני הערכים, ולחצו **Commit changes**. או שלחו את שני הערכים ל-Claude והוא יעדכן.

מרגע זה: `https://aviavigonen-creator.github.io/avi/admin.html` הוא פאנל הניהול.

> המפתח `anon public` בטוח לפרסום: הוא מאפשר רק מה שההרשאות בסכמה מתירות (צפייה במוצרים, יצירת הזמנה). לעולם אל תשימו את `service_role` בקוד האתר.

## שלב 2: תשלום בכרטיס אשראי

בפאנל → **תשלום וצ'אט**:

- **Tranzila**: סמנו "לאפשר תשלום בכרטיס", בחרו Tranzila, והזינו את שם המסוף שקיבלתם. הלקוח מועבר לדף תשלום מאובטח של טרנזילה וחוזר לאתר. יש לבקש מטרנזילה להגדיר `success_url` ו-`fail_url` דינמיים (מגיעים מהאתר).
- **קישור תשלום כללי** (Grow/Meshulam, PayBox לעסקים, Bit לעסקים, PayPlus "דף תשלום"): רוב הספקים נותנים קישור קבוע שאפשר להוסיף לו סכום. הדביקו אותו עם `{sum}` במקום הסכום ו-`{order}` במקום התיאור.
- **Cardcom / PayPlus API / Meshulam API** דורשים קריאת שרת ליצירת דף תשלום. אמרו ל-Claude איזה ספק ותקבלו Edge Function מתאימה.

סטטוס הזמנה אחרי תשלום באשראי הוא **"שולם – לאימות"**: הלקוח חזר מדף התשלום, ואתם מאמתים מול דוח הסליקה ומעבירים ל"שולם". כשתהיה Edge Function לספק שלכם, האימות יהיה אוטומטי.

## שלב 3: קבלות במייל

**חשוב**: בישראל קבלה/חשבונית חייבת לצאת ממערכת מאושרת (חשבונית ירוקה, iCount, Morning, EZcount). כולן יודעות להנפיק קבלה אוטומטית כשחברת הסליקה מדווחת על תשלום. חברו את חברת הסליקה למערכת החשבוניות שלכם, וזה עובד בלי קשר לאתר.

מה שהאתר כן שולח: **אישור הזמנה** ללקוח ו**התראה** לכם, בכל הזמנה חדשה ובכל מעבר ל"שולם". הפעלה:

1. פתחו חשבון ב-[resend.com](https://resend.com) (חינם עד 3,000 מיילים בחודש). ב-**Domains** אמתו את הדומיין שלכם (מוסיפים 3 רשומות DNS אצל הרשם). עד אז אפשר לשלוח מ-`onboarding@resend.dev` רק למייל שלכם.
2. **API Keys → Create** והעתיקו את המפתח.
3. ב-Supabase: **Edge Functions → Deploy a new function** → שם `order-email` → הדביקו את תוכן `supabase/functions/order-email/index.ts` → Deploy.
   (או מהמחשב: `supabase functions deploy order-email`)
4. **Edge Functions → order-email → Secrets**: הוסיפו `RESEND_API_KEY`, `MAIL_FROM` (למשל `מנות של פורים <orders@yourdomain.co.il>`), `OWNER_EMAIL`, `SITE_URL`.
5. **Database → Webhooks → Create a new hook**: שם `order-email`, טבלה `orders`, אירועים **Insert** ו-**Update**, סוג **Supabase Edge Functions**, בחרו `order-email`. שמרו.

מעכשיו כל הזמנה חדשה שולחת מייל תוך שניות.

## שלב 4: צ'אט שירות לקוחות

ברירת המחדל: כפתור וואטסאפ צף שפותח שיחה למספר שבהגדרות. לצ'אט בתוך האתר עם אפליקציה לטלפון:

1. פתחו חשבון חינמי ב-[tawk.to](https://www.tawk.to) והוסיפו Property לאתר.
2. **Administration → Chat Widget**: בקוד ההטמעה מופיע `embed.tawk.to/XXXXX/YYYYY`. העתיקו את `XXXXX/YYYYY`.
3. בפאנל → **תשלום וצ'אט → Tawk.to** הדביקו ושמרו. הורידו את אפליקציית Tawk.to לטלפון כדי לענות.

## שלב 5: דומיין משלכם

1. GitHub → **Settings → Pages → Custom domain**: הקלידו את הדומיין (למשל `manotpurim.co.il`) ולחצו Save. סמנו **Enforce HTTPS** כשיופיע.
2. אצל רשם הדומיין, ב-DNS:
   - `A` records לדומיין הראשי: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` עבור `www` → `aviavigonen-creator.github.io`
3. עדכנו את `SITE_URL` ב-`config.js` לדומיין החדש (חשוב לחזרה מדף התשלום).

## עבודה שוטפת

- **מוצר חדש / שינוי מחיר / תמונה**: בפאנל → מוצרים. בלי קוד, בלי Claude.
- **הזמנה נכנסת**: בפאנל → הזמנות. לחיצה על הטלפון פותחת וואטסאפ ללקוח. שנו סטטוס לפי ההתקדמות: חדשה → שולם → בהכנה → נמסר.
- **שינוי בעיצוב או תכונה חדשה**: בקשו מ-Claude. הוא דוחף למאגר והאתר מתעדכן תוך דקה.
