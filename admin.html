פאנל הניהול עדיין לא מחובר למסד הנתונים

כדי שההזמנות, המוצרים והסטטיסטיקות יעבדו, צריך לחבר את האתר ל-Supabase (מסד נתונים חינמי). זה נעשה פעם אחת:

  1. היכנסו ל-supabase.com, פתחו חשבון, ולחצו New project. בחרו שם, סיסמה ואזור (Europe/Frankfurt).
  2. בתפריט הצד: SQL Editor → New query. הדביקו את תוכן הקובץ supabase/schema.sql מהמאגר ולחצו Run.
  3. Authentication → Users → Add user: צרו משתמש עם המייל והסיסמה שלכם. זה המשתמש של פאנל הניהול.
  4. Project Settings → API: העתיקו את Project URL ואת המפתח anon public.
  5. הדביקו אותם בקובץ config.js במאגר (או שלחו אותם ל-Claude והוא יעדכן), ודחפו ל-GitHub.

אחרי הרענון הבא העמוד הזה יציג מסך התחברות.
